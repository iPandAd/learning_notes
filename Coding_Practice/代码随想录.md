## 链表

### 1. 链表理论基础

链表是一种通过指针串联在一起的线性结构，每一个节点由两部分组成，一个是数据域一个是指针域，最后一个节点的指针域指向 null

链表的入口节点称为链表的头节点也就是 head

链表的类型：

- 单链表
- 双链表：每一个节点有两个指针域，一个指向下一个节点，一个指向上一个节点
- 循环链表：链表首尾相连，可以用来解决约瑟夫环问题

链表在内存中不是连续分布的，通过指针域的指针链接在内存中的各个节点

链表节点定义方式，如果使用默认构造函数，在初始化的时候不能直接给变量赋值

```C++
struct ListNode {
    int val; // 节点上存储的元素
    ListNode *next; // 指向下一个节点的指针
    ListNode(int x) : val(x), next(NULL) {} // 节点的构造函数
};

ListNode* head = new ListNode(5); // 初始化节点
```

### 2. 移除链表元素

链表操作的两种方式：

- 直接使用原来的链表来进行删除操作
- 设置一个虚拟头节点再进行删除操作

此题目也可以递归完成

注意 delete 后正确回收指针

### 4. 反转链表

### 5. 两两交换链表中的节点

## 哈希表

### 1. 哈希表理论基础

哈希表（英文名字为 Hash table，国内也有一些算法书籍翻译为散列表）。哈希表是根据关键码的值而直接进行访问的数据结构

一般哈希表都是用来快速判断一个元素是否出现集合里

哈希函数通过 hashCode 将其他数据格式转化为不同的数值

哈希碰撞：两种解决方法，拉链法和线性探测法

拉链法将发生冲突的元素都存储在链表中，需要选择适当的哈希表大小

线性探测法一定要保证 tableSize 大于 dataSize

std::unordered_set 底层实现为哈希表，std::set 和 std::multiset 的底层实现是红黑树

哈希法：快速判断一个元素是否出现集合里，牺牲了空间换取了时间

### 2. 有效的字母异位词

纯小写字母可以使用数组代替哈希表

> 438 找到字符串中所有字母异位词一题中，需要综合使用滑动窗口和哈希表。定长窗口枚举所有子串并比较出现次数，不定长窗口枚举子串右端点
> 定长窗口原始写法太慢了，每次遍历一个子串后，左侧移除，右侧移入即可。可以直接判断两个容器是否相等
> 定长窗口可以按照右侧从头遍历到尾，只是长度不满足要求时不进行逻辑判断
> 49 字母异位词分组使用暴力求解法会超出时间限制。自定义哈希表需要编写哈希函数，时间复杂度相比以排序后的字符串为键更低，需要掌握这一技巧。

> 自定义哈希函数：`unordered_map`的键类型需要满足可哈希和可比较的条件，需要引入`functional`头文件特化`std::hash`模板，或者在声明`unordered_map`时提供一个自定义哈希函数对象。建议自定义一个哈希函数结构体，在声明`unordered_map`时将结构体作为第三个模板参数传递，定义结构体可声明为`auto`类型，传递模板参数时使用`decltype`。这种情况下使用 Python 操作更简单，`defaultdict(list)`调用`list`作为工厂函数，将`list`转换成`tuple`进行哈希操作

### 3. 两个数组的交集

如果哈希值比较少、特别分散、跨度非常大，使用数组就造成空间的极大浪费

直接使用 set 不仅占用空间比数组大，而且速度要比数组慢，set 把数值映射到 key 上都要做 hash 计算

两个数组的交集 II：使用两个哈希表可以优化空间复杂度，先遍历确定一个哈希表，然后在遍历第二个数组时修改哈希表。给定的数组如果已经排好序，可以使用双指针解决，空间复杂度优化至$O(1)$。如果不能一次加载所有的元素到内存中，可以用一个小型缓存区一边读数据一边遍历数据，等价于问`nums2`是一个流的情况要怎么做

> STL 里使用迭代器可以避免显式的遍历，`unordered_set<int> nums_set(nums1.begin(), nums1.end());`
> 可以选择加入答案列表时从哈希集合里删除元素
> 对关联容器（unordered_map、unordered_set）等使用`erase`函数返回被删除的元素数量

### 4. 快乐数

遇到了要快速判断一个元素是否出现集合里的时候，就要考虑哈希法了

取数值各个位上的单数操作，需要分析为什么值不会无限增大

哈希集合法：对于位运算操作，考虑到数字的位数与底数最高次幂有关，时间复杂度为$O(\log{n})$，使用哈希集合的空间复杂度也为$O(\log{n})$

快慢指针法：考虑到无限循环实际上形成了环，可以参考环形链表题。空间复杂度降低

数学法：找规律，发现只有一个循环`4->16->37->58->89->145->42->20->4`。所有其他数字都在进入这个循环的链上，或者在进入 1 的链上

### 5. 两数之和

map 用来存放我们访问过的元素。遍历数组的时候，只需要向 map 去查询是否有和目前遍历元素匹配的数值，如果有，就找到匹配对，如果没有，就把目前遍历的元素放进 map 中

### 6. 四数相加 II

原始写法将四个数组两两分组，分别使用哈希表统计值出现次数，利用四数之和为零可以简化使用的哈希表

### 7. 赎金信

在本题情况下，使用 map 的空间消耗要比数组大一些，因为 map 要维护红黑树或哈希表，且还要做哈希函数，是费时的

在使用两个数组分别记录的前提下，可以思考如何使用一个数组实现功能

### 8. 三数之和

思路正确，两层 for 循环+哈希法确定第三个数

剪枝操作：排序后第一个元素大于零，直接返回；如果本轮左端点与上一轮相同，去重；

双指针思路：首先对数组进行排序，for 循环遍历左端点。找完一层后如果下一层左端点元素相同，则返回

注意此题目不允许三元组重复，但是组内元素可以重复

此题可以理解为对排序好的数组固定住左端，对剩余部分执行两数之和

### 9. 四数之和

剪枝操作：与三数之和类似，注意判断加和大于目标且加和中更大的一个元素大于等于零才直接返回，因为再往后的元素都大于等于零

更好的剪枝操作：对于第一个数，判断连续四个数的加和大于目标，直接退出外层循环；判断与倒数连续三个数的加和小于目标，直接遍历下一个元素；对于第二个数也有类似优化

此题目需要注意细节，比如加和有可能溢出`int`类型，可以定义一个`long long`加和量进行累加

双指针部分更优雅的写法如下

```C++
for (c++; c < d && nums[c] == nums[c - 1]; c++);
for (d--; c < d && nums[d] == nums[d + 1]; d--);
```

### 10. 总结篇

哈希函数是把传入的 key 映射到符号表的索引上

哈希碰撞处理有多个 key 映射到相同索引上时的情况，普遍方式是拉链法和线性探测法

数组就是简单的哈希表，但是数组的大小是受限的

如果数组空间够大，但哈希值比较少、特别分散、跨度非常大，使用数组就造成空间的极大浪费

前缀表是用来回退的，它记录了模式串与主串不匹配的时候，模式串应该从哪里开始重新匹配

前缀表：记录下标 i 之前（包括 i）的字符串中，有多大长度的相同前缀后缀

前缀：不包含最后一个字符的所有以第一个字符开头的连续子串

后缀：不包含第一个字符的所有以最后一个字符结尾的连续子串

构造 next 数组其实就是计算模式串 s，前缀表的过程。主要分为：1. 初始化；2. 处理前后缀不相同的情况；3. 处理前后缀相同的情况

初始化：`next[i]`表示 i（包括 i）之前最长相等的前后缀长度 j

前后缀不相同：比较`s[i]`和`s[j+1]`，前后缀末尾不相同时向前回退，找 j+1 前一个元素在 next 数组里的值，即`next[j]`

前后缀相同：同时向后移动 i 和 j 说明找到相同的前后缀，同时还要将 j 的长度赋给`next[i]`

如果 j 指向了模式串 t 的末尾，就说明模式串 t 完全匹配文本串 s 里的某个子串了

主要理解`j=next[i]`

> 常见的字符串匹配算法包括暴力匹配、Knuth-Morris-Pratt 算法、Boyer-Moore 算法、Sunday 算法等
> 暴力匹配让模式串与文本串所有长度为 m 的子串均匹配一次
> KMP 算法：核心为前缀函数。前缀函数$\pi(i)(0\leq{i}<m)$表示$s$的子串$s[0:i]$的最长的相等的真前缀与真后缀的长度，真前缀和真后缀定义为不等于自身的前缀和后缀
>
> 前缀函数性质：1. $\pi(i)\leq\pi(i-1)+1$；2. $\text{if}\quad s[i]=s[\pi(i-1)],\pi(i) = \pi(i - 1) + 1$
>
> 库函数写法：haystack.find(needle)

### 7. 重复的子字符串

移动匹配：两个字符串拼接在一起，里面还出现一个相同的字符串，说明是由重复子串组成

KMP：如果一个字符串由重复子串组成，最长相等前后缀不包含的子串一定是字符串的最小重复子串；最长相等前后缀不包含的子串的长度可以被字符串长度整除，不包含的子串就是最小重复子串

> 枚举：时间复杂度$O(n^{2})$
> 字符串匹配：将两个`s`连在一起，并移除第一个和最后一个字符。如果`s`是该字符串的子串，那么`s`就满足题目要求。`(s+s).find(s, 1) != s.size()`
> KMP：实现 API 时，需要在平均时间复杂度和最坏时间复杂度二者之间权衡。普通的暴力匹配算法以及优化的 BM 算法拥有比 KMP 算法更为优秀的平均时间复杂度。可旋转字符串：将`s`的前`i`个字符保持顺序，移动到`s`的末尾，得到的新字符串与`s`相同

## 栈与队列

### 1. 栈与队列理论基础

队列是先进先出，栈是先进后出

三个最为普遍的 STL 版本：1. HP STL，是 C++ STL 的第一个实现版本，而且开放源代码；2. P.J.Plauger STL，P.J.Plauger 参照 HP STL 实现出来的，被 Visual C++编译器所采用，不是开源的；3. SGI STL，由 Silicon Graphics Computer Systems 公司参照 HP STL 实现，被 Linux 的 C++编译器 GCC 所采用，开源软件，源码可读性甚高

这里介绍的栈和队列是 SGI STL 里面的数据结构

栈不提供走访功能，也不提供迭代器

栈是以底层容器完成其所有的工作，对外提供统一的接口，底层容器是可插拔的（也就是说我们可以控制使用哪种容器来实现栈的功能）

栈往往被归类为 container adapter（容器适配器）

栈的底层实现可以是 vector，deque，list，主要是数组和链表的底层实现。

如果没有指定底层实现默认是以 deque 为缺省情况下栈的底层结构；队列底层实现缺省情况下一样使用 deque 实现的

指定 vector 为栈的底层实现，初始化语句如下

```C++
std::stack<int, std::vector<int>> third;
```

队列中先进先出的数据结构，同样不允许有遍历行为，不提供迭代器，SGI STL 中队列一样是以 deque 为缺省情况下的底部结构

指定 list 为底层实现，初始化 queue 的语句如下

```C++
std::queue<int, std::list<int>> third;
```

队列被归类为 container adapter（容器适配器）

> Python 中栈基于列表（list）实现，底层结构是动态数组；队列基于`collections.deque`，底层结构是双向链表，需要避免使用列表直接实现队列
> 多线程环境下生产者-消费者模型使用基于`collections.deque`封装的`queue.Queue`，使用锁保证线程安全

### 2. 用栈实现队列

`peek`函数可以调用已有的`pop`函数，获取后再重新 push 回去

### 3. 用队列实现栈

队列是先进先出的规则，把一个队列中的数据导入另一个队列中，数据的顺序并没有变，并没有变成先进后出的顺序

用两个队列 que1 和 que2 实现栈的功能，que2 完全就是一个备份的作用

一个队列在模拟栈弹出元素的时候只要把队列头部的元素（除了最后一个元素外）重新添加到队列尾部，此时再去弹出元素就是栈的顺序了

### 4. 有效的括号

编译器在词法分析的过程中处理括号、花括号等符号的逻辑，也是使用了栈这种数据结构

### 8. 前 K 个高频元素

优先级队列：其实就是一个披着队列外衣的堆，因为优先级队列对外接口只是从队头取元素，从队尾添加元素

缺省情况下 priority_queue 利用 max-heap 完成对元素的排序，这个大顶堆是以 vector 为表现形式的 complete binary tree

堆是一棵完全二叉树，树中每个节点的值都不小于（或不大于）其左右孩子的值

要统计最大前 k 个元素，只有小顶堆每次将最小的元素弹出，最后小顶堆里积累的才是前 k 个最大元素

std::vector<std::string> split(const std::string& s, char delimiter) {

## 二叉树

### 1. 二叉树理论基础

解题过程中二叉树有两种主要的形式：满二叉树和完全二叉树

满二叉树：如果一棵二叉树只有度为 0 的节点和度为 2 的节点，并且度为 0 的节点在同一层上，则这棵二叉树为满二叉树

完全二叉树：除了最底层节点可能没填满外，其余每层节点数都达到最大值，并且最下面一层的节点都集中在该层最左边的若干位置

优先级队列其实是一个堆，堆就是一棵完全二叉树，同时保证父子节点的顺序关系

二叉搜索树是一个有序树：若它的左子树不空，则左子树上所有节点的值均小于它的根节点的值；若它的右子树不空，则右子树上所有节点的值均大于它的根节点的值；它的左右子树也分别为二叉搜索树

平衡二叉搜索树：又被称为 AVL（Adelson-Velsky and Landis）树，它是一棵空树或它的左右两个子树的高度差的绝对值不超过 1，并且左右两个子树都是一棵平衡二叉树

C++中 map、set、multimap、multiset 的底层实现都是平衡二叉搜索树

二叉树可以链式存储，也可以顺序存储。链式存储方式就用指针，顺序存储的方式就是用数组

用数组来存储二叉树：如果父节点的数组下标是`i`，那么它的左孩子就是`i*2+1`，右孩子就是`i*2+2`

二叉树主要有两种遍历方式：1. 深度优先遍历：先往深走，遇到叶子节点再往回走（前序遍历、中序遍历、后序遍历）；2. 广度优先搜索：一层一层的去遍历（层序遍历）

前中后指的就是中间节点的遍历顺序

### 2. 二叉树的递归遍历

递归三要素：1. 确定递归函数的参数和返回值；2. 确定终止条件；3. 确定单层递归的逻辑

前序遍历：访问根节点-左子树-右子树的方式遍历这棵树

后序遍历：访问左子树-右子树-根节点的方式遍历这棵树

中序遍历：访问左子树-根节点-右子树的方式遍历这棵树

### 3. 二叉树的迭代遍历

前序遍历：先将根节点放入栈中，然后将右孩子加入栈，再加入左孩子

中序遍历：处理顺序和访问顺序是不一致的，需要借用指针的遍历来帮助访问节点，栈则用来处理节点上的元素

后序遍历：调整一下前序遍历的代码顺序，再反转数组

前序遍历中访问节点和处理节点可以同步，但是中序遍历无法做到同步

### 4. 二叉树的统一迭代法

中序遍历使用栈无法同时解决访问节点和处理节点不一致的情况

将访问的节点放入栈中，把要处理的节点也放入栈中但是要做标记

方法一：要处理的节点放入栈之后，紧接着放入一个空指针作为标记

方法二：加一个 boolean 值跟随每个节点，false 表示需要为该节点和它的左右儿子安排在战中的位次，true 表示该节点的位次之前已经安排过了，可以收割节点了

### 5. 二叉树的层序遍历

队列先进先出，符合一层一层遍历的逻辑，而用栈先进后出适合模拟深度优先遍历也就是递归的逻辑

层序遍历方式就是图论中的广度优先遍历，只不过我们应用在二叉树上

> 二叉树的右视图：也可以使用深度优先搜索，优先访问右子树，以递归的方式实现。注意 lambda 函数的递归实现形式
> 填充每个节点的下一个右侧节点指针：需要明确前一个节点和当前节点，前一节点在当前层初始化后通过`next`指针更新。注意`node_pre`遍历一层后到最后一个节点，需要给`next`属性赋值。或者每层先获取`size`，然后判断是否是最后一个节点，如果不是最后一个节点则给`next`属性赋值当前队列队首
> 填充每个节点的下一个右侧节点指针：也可以在 BFS 的时候一边遍历当前层的节点，一边把下一层的节点连接起来，这样就无需存储下一层的节点了，只需要拿到下一层链表的头节点。这样的好处在于降低了空间复杂度，`Node* nxt = &dummy`一行使得`nxt`节点获取`dummy`引用赋值，修改`nxt`节点会同时修改`dummy`节点，给`nxt`重新赋值会断开和`dummy`的引用关系
> 在写递归函数时，可以假设递归返回的结果一定是正确的。其实这种说法本质上就是**数学归纳法**

二叉树的层序遍历，就是图论中的广度优先搜索在二叉树中的应用，需要借助队列来实现

### 6. 翻转二叉树

这道题目使用前序遍历和后序遍历都可以，唯独中序遍历不方便，因为中序遍历会把某些节点的左右孩子翻转了两次

递归三部曲：1. 确定递归函数的参数和返回值，参数就是要传入节点的指针，返回值可以直接使用题目定义好的函数；2. 确定终止条件，当前节点为空的时候，就返回；3. 确定单层递归的逻辑，前序遍历，所以先交换左右孩子节点，然后反转左子树，反转右子树

> 可以直接利用函数自身递归，迭代方式使用栈模拟递归过程

### 9. 二叉树的最大深度

本题可以使用前序（中左右），也可以使用后序遍历（左右中），使用前序求的就是深度，使用后序求的是高度

二叉树节点的深度：指从根节点到该节点的最长简单路径边的条数或者节点数（取决于深度从 0 开始还是从 1 开始）

二叉树节点的高度：指从该节点到叶子节点的最长简单路径边的条数或者节点数（取决于高度从 0 开始还是从 1 开始）

根节点的高度就是二叉树的最大深度

后序遍历计算树的高度

1. 确定递归函数的参数和返回值：参数就是传入树的根节点，返回这棵树的深度
2. 确定终止条件：如果为空节点的话，就返回 0，表示高度为 0
3. 确定单层递归的逻辑：先求它的左子树的深度，再求右子树的深度，最后取左右深度最大的数值再 +1

前序遍历顺序，真正求深度的逻辑

### 10. 二叉树的最小深度

前序求深度，后序求高度

求二叉树的最小深度和求二叉树的最大深度的差别主要在于处理左右孩子不为空的逻辑

层序遍历：左右孩子都为空的时候说明遍历到最低点了

> 使用前序遍历可以看作自顶向下遍历，需要传入一个计数器表示路径上的节点个数

### 11. 完全二叉树的节点个数

假设最后一层叶子节点没有满，分别递归左孩子和右孩子，递归到某一深度一定会有左孩子或者右孩子为满二叉树，此时可以直接计算

如果整个树不是满二叉树，就递归其左右孩子，直到遇到满二叉树为止

在完全二叉树中，如果递归向左遍历的深度等于递归向右遍历的深度，说明就是满二叉树

计算 2 的幂可以使用位运算

> 由于完全二叉树的性质，其子树一定有一棵是满的，所以一定会触发 `left_depth == right_depth`，只消耗$O(\log{n})$的复杂度而不会继续递归。算法的递归深度就是树的高度$O(\log{n})$每次递归所花费的时间就是 while 循环，需要$O(\log{n})$，总体的时间复杂度是$O(\log{n}\times\log{n})$

### 12. 平衡二叉树

求深度可以从上到下去查，所以需要前序遍历；而高度只能从下到上去查，所以只能后序遍历

如果已经不是二叉平衡树了，可以返回 -1 来标记已经不符合平衡树的规则了

可以先定义一个函数专门用来求高度，通过栈模拟的后序遍历迭代找每一个节点的高度

此题用迭代法，其实效率很低，因为没有很好的模拟回溯的过程，所以迭代法有很多重复的计算

求深度适合用前序遍历，而求高度适合用后序遍历

> 当前树的深度等于左子树的深度与右子树的深度中的最大值 +1
> 方法一：后序遍历 + 剪枝（从底至顶）：节点左右子树的深度差小于等于 1，则返回当前子树的深度，否则返回 -1。左右子树深度为 -1 代表左右子树不是平衡树，直接返回
> 方法二：先序遍历 + 判断深度（从顶至底）：思路是构造一个获取当前子树深度的函数，通过比较某子树的左右子树的深度差是否成立，来判断某子树是否是二叉平衡树。满二叉树高度的复杂度为$O(\log{n})$，调用深度计算函数判断各层节点的对应子树深度，时间复杂度为$O(n)$

### 13. 二叉树的所有路径

递归和回溯就是一家的

### 1. 回溯算法理论基础

回溯法也可以叫做回溯搜索法，它是一种搜索的方式

回溯是递归的副产品，只要有递归就会有回溯

回溯的本质是穷举，穷举所有可能，然后选出我们想要的答案，如果想让回溯法高效一些，可以加一些剪枝的操作

回溯法一般可以解决如下几种问题：

- 组合问题：N 个数里面按一定规则找出 k 个数的集合

- 排列问题：N 个数按一定规则全排列，有几种排列方式

组合不强调元素顺序，排列强调元素顺序

## 贪心算法

### 1. 贪心算法理论基础

贪心的本质是选择每一阶段的局部最优，从而达到全局最优

贪心算法并没有固定的套路。靠自己手动模拟，如果模拟可行，就可以试一试贪心策略，如果不可行，可能需要动态规划

最好用的策略就是举反例，如果想不到反例，就试一试贪心

贪心算法一般分为如下四步：将问题分解为若干个子问题；找出适合的贪心策略；求解每一个子问题的最优解；将局部最优解堆叠成全局最优解

### 2. 分发饼干

局部最优：大饼干喂给胃口大的，充分利用饼干尺寸喂饱一个，全局最优就是喂饱尽可能多的小孩

从后向前遍历小孩数组，用大饼干有限满足胃口大的；也可以换一个思路，小饼干先喂饱小胃口

### 3. 摆动序列

局部最优：删除单调坡度上的节点（不包括单调坡度两端的节点），那么这个坡度就可以有两个局部峰值

整体最优：整个序列有最多的局部峰值，从而达到最长摆动序列

题目要求的是最长摆动子序列的长度，所以只需要统计数组的峰值数量就可以了

要考虑三种情况：

- 情况一：上下坡中有平坡
- 情况二：数组首尾两端
- 情况三：单调坡中有平坡

本题异常情况的本质，就是要考虑平坡：一个是上下中间有平坡，一个是单调有平坡

动态规划：当前考虑的这个数，要么是作为山峰（即`nums[i] > nums[i - 1]`），要么是作为山谷（即`nums[i] < nums[i - 1]`）

设 dp 状态`dp[i][0]`，表示考虑前 i 个数，第 i 个数作为山峰的摆动子序列的最长长度

设 dp 状态`dp[i][1]`，表示考虑前 i 个数，第 i 个数作为山谷的摆动子序列的最长长度

初始状态为：`dp[0][0] = dp[0][1] = 1`

进阶：可以用两棵线段树来维护区间的最大值

### 4. 最大子序和

暴力解法：第一层 for 设置起始位置，第二层 for 遍历数组寻找最大值

局部最优：当前连续和为负数时立刻放弃，从下一个元素重新计算连续和

全局最优：选取最大连续和

> 本题使用贪心算法可以优化空间复杂度

### 5. 贪心周总结

贪心的本质是选择每一阶段的局部最优，从而达到全局最优

严格的数据证明一般有：数学归纳法；反证法

## 动态规划

### 1. 动态规划理论基础

如果某一问题有很多重叠子问题，使用动态规划是最有效的

动态规划中每一个状态一定是由上一个状态推导出来的，这一点就区分于贪心，贪心没有状态推导，而是从局部直接选最优的

动态规划五部曲：1. 确定 dp 数组及下标的含义；2. 确定递推公式；3. dp 数组如何初始化；4. 确定遍历顺序；5. 举例推导 dp 数组

### 2. 斐波那契数

动态规划五部曲：1. 确定 dp 数组以及下标的含义；2. 确定递推公式；3. dp 数组如何初始化；4. 确定遍历顺序；5. 举例推导 dp 数组

`n == 0`或`n == 1`时，直接返回

> 生成第 n 项的做法有以下几种：1. 暴力搜索；2. 记忆化递归；3. 动态规划。
> 状态压缩：由于第 i 项只与第 i - 1 和 第 i - 2 项有关，因此只需要初始化三个整型变量，利用辅助变量使两数字交替前进即可
> 矩阵快速幂：利用矩阵乘法降低复杂度为 $O(\log{n})$
> 通项公式：时间复杂度与代码中使用的`pow`函数的时空复杂度与 CPU 支持的指令集相关

### 3. 爬楼梯

题目中说 n 是一个正整数，其实不应该讨论`dp[0]`的初始化

很多动态规划的题目其实都是当前状态依赖前两个，或者前三个状态，都可以做空间上的优化

### 4. 使用最小花费爬楼梯

`dp[i]`定义：到达第`i`台阶所花费的最少体力为`dp[i]`

到达第 0 个台阶是不花费体力的，因此`dp[0] = 0, dp[1] = 0`
