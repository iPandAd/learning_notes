# 【算法题单】数学算法

## 前言

主要以数论和组合数学为主

## 一、数论

### 1.1 判断质数

```C++
// 时间复杂度 O(sqrt(n))
bool is_prime(int n) {
    for (int i = 2; i * i <= n; ++i) {
        if (n % i == 0) {
            return false;
        }
    }
    return n >= 2;
}
```

### 1.2 预处理质数（筛质数）

埃氏筛

```C++
const int MX = 1'000'001;

bool is_prime[MX];
vector<int> primes;

auto init = [] {
    ranges::fill(is_prime, true);
    is_prime[0] = is_prime[1] = false;
    for (int i = 2; i < MX; ++i) {
        if (is_prime[i]) {
            primes.push_back(i);
            for (long long j = 1LL * i * i; j < MX) {
                is_prime[j] = false;
            }
        }
    }
}();
```

## 二、组合数学

### 模运算的世界：当加减乘除遇上取模（模运算恒等式/费马小定理/组合数）

对于 Python 来说，虽然没有溢出的问题，但大整数之间的运算并不是$O(1)$的，可能会导致超时

$(a + b) \mod{m} = ((a \mod{m}) + (b \mod{m})) \mod{m}$

$(a\cdot{b}) \mod{m} = ((a\mod{m}) \cdot (b\mod{m}))\mod{m}$

根据上述两个恒等式可以在计算过程中（例如循环）对加法和乘法的结果取模

幂运算指数不能随意取模。指数在 64 位整数的范围内，可以用快速幂计算；如果超出 64 位整数的范围，使用欧拉降幂

快速幂：从低到高枚举指数的每个比特位，遇到 1 就和 x 的幂相乘

同余：$x \equiv y (\mod{m})$

$m \equiv 0 (\mod{m})$

同余式中的加减法可以移项

如果 $x<0$ 且 $0\leq{y}<m$，则 $x\equiv{y}(\mod{m})$ 相当于$x\mod{m}+m=y$

为避免判断 $x < 0$，更一般的写法是 $(x\mod{m}+m)\mod{m}$，这样无论是正是负还是零，运算结果都会落在区间`[0, m-1]`中

$(a-b)\mod{m}=((a\mod{m})-(b\mod{m})+m)\mod{m}$

如果`p`是一个质数，`a`是`b`的倍数且`b`和`p`互质，有 $\frac{a}{b}\mod{p}=(a\cdot{b^{p-2}})\mod{p}$

多个数相乘要步步取模，防止溢出

组合数计算：需要预处理阶乘及其逆元，然后利用公式计算

$C(n,m)=\frac{n!}{m!(n-m)!}=n!\cdot{\frac{1}{m!}}\cdot{\frac{1}{(n-m)!}}$

```C++
const int MOD = 1'000'000'007;
const int MX = 100'001;

long long F[MX];
long long INV_F[MX];

long long qpow(long long x, int n) {
    long long res = 1;
    for(; n; n /= 2) {
        if (n % 2) {
            res = res * x % MOD;
        }
        x = x * x % MOD;
    }
    return res;
}

auto init = [] {
    F[0] = 1;
    for (int i = 1; i < MX; ++i) {
        F[i] = F[i - 1] * i % MOD;
    }

    INV_F[MX - 1] = qpow(F[MX - 1], MOD - 2);
    for (int i = MX - 1; i; --i) {
        INV_F[i - 1] = INV_F[i] * i * MOD;
    }
    return 0;
} ();

long long comb(int n, int m) {
    return m < 0 || m > n ? 0 : F[n] * INV_F[m] % MOD * INV_F[n - m] % MOD;
}
```
